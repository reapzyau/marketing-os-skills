# Copy Type Blueprints

Structural skeletons for each copy type. Each section references which framework drives it.

---

## Headlines (Simple)

**Structure:**
1. Pick 2-3 Caples categories to generate from (self-interest, news, curiosity, quick/easy, command)
2. Generate 3-5 options per category using formula templates
3. Score each against Ogilvy's headline rules (specificity, benefit, audience flagging)
4. Present top 10 ranked by strength

**Driven by:** Caples formulas + Ogilvy headline rules

---

## Ad Copy — Facebook/Meta/Google (Simple)

**Structure:**
1. **Hook** (1-2 sentences) — Caples headline formula + Sugarman Axiom 3 (short first sentence)
2. **Problem agitation** (2-3 sentences) — Sugarman Trigger 11 (prospect nature) + 21 (fear)
3. **Solution bridge** (1-2 sentences) — Sugarman Axiom 9 (sell the concept)
4. **Proof point** (1 sentence) — Sugarman Trigger 29 (specificity)
5. **CTA** (1 sentence) — Sugarman Element 23 (ask for the order) + Trigger 20 (urgency)

**Total:** 80-150 words
**Driven by:** Sugarman slippery slide + triggers, Ogilvy headlines, Caples formulas

---

## Email — Single (Medium)

**Structure:**
1. **Subject line** — Caples curiosity formula or Ogilvy news angle
2. **Opening line** (1 sentence) — Sugarman Axiom 3 (shortest possible)
3. **Story/hook** (2-4 sentences) — Halbert conversational tone + Sugarman Trigger 26
4. **Bridge to value** (1-2 sentences) — Sugarman Axiom 9 (concept)
5. **The point** (2-3 sentences) — Sugarman Trigger 5 (value) + specificity
6. **CTA** (1 sentence) — Halbert one CTA rule
7. **P.S.** — Kennedy P.S. rule (2nd most-read element — reinforce offer or add urgency)

**Total:** 150-300 words
**Driven by:** Halbert A-pile + conversational tone, Sugarman slippery slide, Kennedy P.S.

---

## Email Sequence (Medium)

**Structure:**
1. **Email 1: Story + Value** — Establish relationship, deliver value, one soft CTA
2. **Email 2: Problem Agitation** — Deepen the pain, share relatable example
3. **Email 3: Solution Introduction** — Present the concept (not the product yet)
4. **Email 4: Proof** — Testimonials, case studies, data, specificity
5. **Email 5: Objection Handling** — Address top 3 objections, damaging admission if appropriate
6. **Email 6: Urgency + Offer** — Full offer with deadline, guarantee, P.S.
7. **Email 7: Last Chance** — Final urgency, risk reversal, direct ask

**Driven by:** Kennedy sequence strategy, Sugarman triggers (graduated application), Halbert A-pile

## Landing Page (Medium)

**Structure:**
1. **Hero section** — Headline (Caples self-interest or Ogilvy news) + subheadline (expand) + CTA
2. **Problem section** — 3 pain points in reader's language (Sugarman Trigger 11)
3. **Solution section** — The concept, not the product (Sugarman Axiom 9)
4. **How it works** — 3-step explanation, simple (Sugarman Element 5)
5. **Proof section** — Testimonials, numbers, logos (Sugarman Triggers 4, 29)
6. **Value stack** — What they get, perceived value per item (Kennedy)
7. **Objection handling** — FAQ or anticipate/resolve blocks (Sugarman Elements 8-9)
8. **Guarantee** — Satisfaction conviction (Sugarman Trigger 9)
9. **Final CTA** — Urgency + direct ask (Sugarman Trigger 20, Element 23)

**Driven by:** Sugarman copy sequence adapted for web, Kennedy value stack, Ogilvy headlines

## Social Post — Skool/LinkedIn/X (Simple)

**Structure:**
1. **Hook** (1 sentence) — Curiosity or contrarian opener (Sugarman Axiom 8)

3. **Insight** (1-2 sentences) — The takeaway, framed as concept (Sugarman Axiom 9)

**Total:** 80-200 words
**Driven by:** Sugarman slippery slide (axioms 2-6), Halbert conversational tone

## Sales Letter (Complex)

**Structure — 3 Agent Assembly:**

### Agent A: Opening & Headlines
1. **Headline** — 10 options using Caples formulas, scored against Ogilvy rules
2. **Subheadline** — Expand headline, add specificity
3. **Opening** — Short first sentence (Sugarman Axiom 3) + harmony building (Axiom 5)
4. **Problem story** — Personal narrative establishing the problem (Halbert conversational)
5. **Agitation** — Deepen the pain using Sugarman Trigger 21 (fear) + 11 (prospect nature)

### Agent B: Body & Persuasion
6. **Solution reveal** — The concept (Sugarman Axiom 9) + linking (Trigger 14)
7. **Proof stack** — Testimonials, data, case studies (Sugarman Triggers 4, 29)
8. **Mechanism** — How it works, technical credibility (Sugarman Element 7)
9. **Objection handling** — Anticipate and resolve all (Sugarman Elements 8-9)
10. **Damaging admission** — Honest flaw acknowledged (Kennedy)
11. **Bugaboo** — Shared enemy to blame (Kennedy)
12. **Value delivery** — Factors of value for each component

### Agent C: Close & Mechanics
13. **Value stack summary** — All components with perceived values (Kennedy)
14. **Price presentation** — Anchored, compared, justified (Sugarman Triggers 5-7)
15. **Guarantee** — Satisfaction conviction beyond basic trial (Sugarman Trigger 9)
16. **Urgency** — Truthful scarcity or deadline (Sugarman Trigger 20)
17. **Bonuses** — 2-3 bonuses addressing specific objections
18. **Final CTA** — Direct ask with urgency (Sugarman Element 23)
19. **P.S.** — Reinforce key benefit or urgency (Kennedy, Halbert)

**Driven by:** All 5 authors — Kennedy for structure, Sugarman for psychology, Halbert for tone, Ogilvy for headlines, Caples for formulas

## VSL Script (Complex)

Same structure as Sales Letter but adapted for spoken delivery:
- Replace "headline/subheadline" with "hook/pattern interrupt"
- Add pacing notes: [PAUSE], [SLOW DOWN], [EMPHASIS]
- Shorter sentences throughout (spoken vs. written)
- Visual cues: [SHOW: testimonial], [SHOW: demo], [SHOW: price]
- Open loop structure: plant questions early, answer them later (Sugarman Seeds of Curiosity)

**Driven by:** Same as Sales Letter + Sugarman's infomercial principles from Chapter 36

3. Identify top 3 weaknesses
4. Provide specific rewrite suggestions for each weakness
5. Rate overall: Strong / Needs Work / Rewrite

## Trigger Mapping (Simple)

**Structure:**
1. Read the copy/offer description
2. Map all 31 Sugarman triggers against the product/audience
3. Score each: Strong (already present), Opportunity (could add), N/A (doesn't apply)
4. Recommend top 5 triggers to strengthen or add
5. Provide specific implementation suggestions for each

**Driven by:** Sugarman triggers (full 31)
