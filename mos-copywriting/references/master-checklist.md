# Master Quality Checklist

Synthesized from Sugarman, Kennedy, Ogilvy, Caples, and Halbert. Run the appropriate tiers based on copy type.

---

## Tier Routing

| Copy Type | Run Tiers |
|-----------|-----------|
| Headlines | 1 + 2 + 5 |
| Social posts | 1 + 5 |
| Ad copy | 1 + 2 + 5 |
| Email | 1 + 3 + 5 |
| Landing page | 1 + 2 + 3 + 5 |
| Sales letter | 1 + 2 + 3 + 4 + 5 |
| VSL script | 1 + 2 + 3 + 4 + 5 |
| Copy review | All 5 tiers |

---

## Tier 1: Universal (All Copy Types)

These apply to every piece of copy regardless of format.

- [ ] **Concept over product** — Are we selling a concept/idea, not just features? (Sugarman Axiom 9)
- [ ] **One reader** — Is it written to ONE person, not a crowd? (Sugarman Axiom 12, Halbert)
- [ ] **Emotional core** — Does it sell on emotion? Is there a feeling, not just information? (Sugarman Ch.11)
- [ ] **Logical justification** — Are there logical reasons to support the emotional decision? (Sugarman Trigger 6)
- [ ] **Specificity** — Are claims specific, not vague? Numbers, names, details? (Sugarman Trigger 29, Halbert)
- [ ] **Clarity** — Can a 12-year-old understand it? No jargon, no complexity? (Sugarman Element 11, Ogilvy)
- [ ] **One CTA** — Is there exactly ONE clear action to take? (Halbert)
- [ ] **Honesty check** — Would you be comfortable if your smartest customer read every word? (Sugarman Trigger 2)
- [ ] **Voice match** — Does it sound like a person talking, not a company broadcasting? (Halbert A-pile test)
- [ ] **No clichés** — Zero "game-changing," "cutting-edge," "unlock the power of" language? (Sugarman Element 12)

---

## Tier 2: Headlines & Hooks

Run for any copy that has a headline, subject line, or opening hook.

- [ ] **5x test** — If only the headline were read, does it convey value? (Ogilvy 5x rule)
- [ ] **Self-interest** — Does the headline promise a benefit to the reader? (Caples Category 1)
- [ ] **Curiosity gap** — Does it create a question the reader needs answered? (Sugarman Axiom 8)
- [ ] **Audience flagging** — Does it call out who it's for? (Ogilvy audience flagging)
- [ ] **Specificity in headline** — Does it include a specific number, result, or timeframe? (Caples + Ogilvy)
- [ ] **First sentence test** — Is the first sentence SHORT (under 12 words)? (Sugarman Axiom 3)
- [ ] **News angle** — If possible, does it frame as news/announcement? (Caples Category 2, Ogilvy)
- [ ] **Power words** — Does it include at least one: free, new, how to, discover, secret, you, because? (Ogilvy)
- [ ] **Passes "so what?" test** — Would a busy person care? Does it answer "why should I read this?" |

---

## Tier 3: Body Copy

Run for emails, landing pages, sales letters, VSLs — anything with body text.

- [ ] **Slippery slide** — Does each sentence compel reading the next? Read aloud — any place you slow down? (Sugarman Axiom 6)
- [ ] **Seeds of curiosity** — Are there mid-copy hooks? "But here's where it gets interesting..." (Sugarman Ch.10)
- [ ] **Objections anticipated** — Are the top 3-5 objections raised AND resolved? (Sugarman Elements 8-9)
- [ ] **Proof included** — Testimonials, data, case studies, demonstrations? (Kennedy, Sugarman Trigger 4)
- [ ] **Buying environment** — Does the tone/design match the price point? Premium = refined. Budget = energetic. (Sugarman Axiom 4)
- [ ] **Yes momentum** — Do the opening paragraphs build agreement? Reader nodding along? (Sugarman Axiom 5, Kennedy Yes Sequence)
- [ ] **Story element** — Is there at least one story, example, or narrative? (Sugarman Trigger 26, Halbert)
- [ ] **Rhythm variation** — Are sentence lengths varied (a short punch, a medium connector, an occasional longer line that earns its length)? Achieve variation by varying length, NOT by stacking parallel fragments — the staccato triad is now a tell (see prose-craft-rules.md). (Sugarman Element 13)
- [ ] **Physical facts present** — If selling a product, are all specs included? (Sugarman Element 15)
- [ ] **Technical credibility** — Is there at least one technical detail that adds perceived value? (Sugarman Element 7)
- [ ] **Damaging admission** — If appropriate, is there an honest flaw acknowledged? (Kennedy)
- [ ] **Length justified** — Is copy long enough to persuade but not a word longer? (Sugarman Axiom 11)

---

## Tier 4: Close & Mechanics

Run for sales letters, landing pages, VSLs — anything that needs to convert.

- [ ] **Offer summary** — Is what they get clearly summarized near the close? (Sugarman Element 20)
- [ ] **Value stack visible** — Can they see all components and their value at a glance? (Kennedy)
- [ ] **Guarantee present** — Is there a satisfaction conviction that goes beyond basic? (Sugarman Trigger 9)
- [ ] **Urgency truthful** — Is there a genuine reason to act now, not manufactured pressure? (Sugarman Trigger 20)
- [ ] **Justify the purchase** — Is there ammunition they can use to explain the purchase to others? (Sugarman Trigger 6)
- [ ] **P.S. used** — For letters/emails, is there a P.S.? It's the 2nd most-read element. (Kennedy, Halbert)
- [ ] **Order ease** — Is the path to purchase crystal clear and friction-free? (Sugarman Element 22)
- [ ] **Asked for the order** — Is there a direct, explicit ask? Not implied — stated. (Sugarman Element 23)
- [ ] **Risk reversal** — Is the risk clearly shifted from buyer to seller? (Kennedy, Sugarman)
- [ ] **Bugaboo present** — Is there a shared enemy/villain they can blame? (Kennedy)

---

## Tier 5: Prose Craft (Anti-AI Patterns)

Run on all copy types. These checks catch the mechanical tells of AI-generated or committee-written copy.

- [ ] **Punctuation & cadence tells** — At most ONE em dash (—) in the whole piece, zero preferred; never a hyphen substituting for the same aside (restructure into commas/periods/colons). AND no staccato/anaphoric triad used as a default or closer ("One task. One Claude. One pass." / "Real systems, real results, no theory"). (Supersedes the old "zero em dashes" rule — see prose-craft-rules.md)
- [ ] **Zero ellipses in body** — No trailing "..." in body copy (dialogue exceptions only)
- [ ] **No phrase repetition** — No 3+ word phrase appears 3+ times (excluding product name and primary concept)
- [ ] **No structure repetition** — No 3+ consecutive paragraphs start the same way
- [ ] **Contractions used naturally** — Fewer than 3 stiff constructions ("it is", "do not", "they are", "you will", "we have") unless formal tone specified
- [ ] **Empathy in opening** — First 2-3 sentences acknowledge the reader's situation, problem, or goal before presenting anything
- [ ] **Concrete example per section** — Every major section (or every 300-400 words) contains at least one specific example, scenario, or mini case study
- [ ] **No filler phrases** — Zero instances of "it's important to note", "in today's world", "when it comes to", "at the end of the day", etc.
- [ ] **Sentence length variation** — No 3 consecutive sentences of the same length. Mix of short (6-10 words), medium (15-20), and occasional longer sentences
- [ ] **Specificity level 2+** — No vague claims ("many companies see results"). Every claim has at minimum a percentage, timeframe, or named example
